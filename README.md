# גימטריבון — Gimatrivon

מנוע גימטריה + השוואה + חיפוש בתנ״ך (39), משנה (63), רש״י (77), תרגום אונקלוס (5) ותרגום יונתן (26), ומשנה תורה לרמב״ם (84 ספרי הלכות) עם כסף משנה, השגות הראב״ד ומשנה למלך. במסך הקריאה גם ש״ס עם רש״י ותוספות, וטור עם בית יוסף וב״ח. **שימוש: לחצו פעמיים על `index.html`.** אין צורך באינטרנט, Node, npm, Python או שרת — **מלבד** כפתור "✉ צור קשר" (טופס יצירת-קשר דרך EmailJS), שהוא היחיד באפליקציה הדורש רשת בפועל, ורק כשלוחצים בו על "שליחה".

## סביבת עבודה (מסך אחד)
שני צדדים (א׳ בימין, ב׳ בשמאל). לכל צד, מהקצה אל המרכז: **סינון** (סוגי גימטריה – ברירת מחדל הכול, טווח פרקים, עץ מקורות) ← **תוצאות החיפוש במקורות** ← **פרטי הגימטריה** (לתוצאה שנבחרה) ← **קלט + ערכי כל השיטות**. האזור התחתון במרכז שמור להמשך. הגלילה רק בתוך פאנלים. מתחת ל-1440px הפריסה הופכת לשתי עמודות; מתחת ל-860px מוצג צד אחד בכל פעם (מתג בכותרת).

## קריאה ומפרשים
מתג "קריאה ומפרשים" בכותרת (או `index.html#read`) פותח את התנ״ך, המשנה והרמב״ם כספר פתוח: רש״י, ברטנורא, או כסף משנה, הראב״ד ומשנה למלך (אפשר לכבות כל אחד ב"תצוגה") בתחתית הדף, ותרגום אונקלוס או יונתן בטור צד ("ספר") או מול כל פסוק ("פסוק מול תרגום"). "תצוגה" בוחרת תרגום, כתב רש״י או רגיל וגודל אותיות. הקפיצה למקום נעשית מהכפתור "ספר · פרק" (Ctrl G) או בהקלדה בתיבת החיפוש, למשל ״שמות יב ב״, גם בראשי תיבות וקיצורים (״ש״א ג״, ״ב״מ נט:״, ״הל׳ ת״ת ג״, ״בר׳ א ג״), עם הצעות ספרים תוך כדי הקלדה. מכל תוצאה בתוצאות החיפוש במקורות (במסך הגימטריה) אפשר לעבור ישר למקום שלה בספר, בכפתור הספר הפתוח שליד ⧉; תוצאה במפרש או בתרגום פותחת את הספר שעליו הם. חיפוש בתוך הטקסט: Ctrl K. דפדוף: חיצים או החלקה. הדפסה ו-PDF (כפתור המדפסת או Ctrl P): שני עמודים על כל דף A4 לרוחב, צבעוני או שחור-לבן על רקע לבן. הקוד נמצא ב-`reader.js`.

ש״ס: בחלון המעבר יש לשונית ש״ס (או הקלדה, למשל ״ברכות ב:״). שתי תצוגות: "צורת הדף" (פריסת וילנא מחושבת, עם [daf-renderer](vendor/daf-renderer.LICENSE.txt), MIT) ו"גמרא ומפרשים". לחיצה על קטע פותחת אותו עם פירושיו. הנתונים ב-`generated/talmud/` נבנים ב-`python3 scripts/build-talmud.py <תיקיית יצוא ספריא>`.

טור, בית יוסף וב״ח: בחלון המעבר יש לשונית טור (או הקלדה, למשל ״או״ח ס״ או ״יו״ד קצג״). העימוד בסגנון מהדורת "שירת דבורה": הטור באמצע למעלה בכתב מרובע, ב״ח בטור הימני ובית יוסף בשמאלי בכתב רש״י, מקיפים את הטור וממשיכים מתחתיו. סימני (א) ו-[א] בטור מראים איפה מתחיל כל דיבור, ולחיצה עליהם או על דיבור פותחת אותו באותיות גדולות. כל חלק נטען רק כשפותחים סימן בו. הנתונים ב-`generated/tur/` נבנים ב-`python3 scripts/build-tur.py <תיקיית יצוא ספריא>`.

## הוספת מקורות
`python3 scripts/build-sources.py <go/data> <Onkelos>` — מוסיף רש״י/אונקלוס/תרגום יונתן ל-`generated/corpus.bundle.js` (תנ״ך ומשנה אינם משתנים; ניתן להריץ שוב).
`python3 scripts/build-rambam.py [תיקיית מטמון]` ואחריו `node scripts/split-corpus.js` — מוריד מיצוא הנתונים של ספריא את משנה תורה (מנוקד) ושלושת המפרשים ומוסיף אותם לקורפוס (קטגוריות 7–10; ניתן להריץ שוב).

## מבנה
- `index.html`, `styles.css`, `app.js` — הממשק (RTL, Vanilla JS).
- `reader.js` — מסך "קריאה ומפרשים" (עימוד, תרגום, מפרש, קפיצה וחיפוש).
- `vendor/fonts/` — גופני Frank Ruhl Libre ו-Noto Rashi Hebrew (OFL) למסך הקריאה, מקומיים.
- `engine.js` — נרמול, כל שיטות הגימטריה, השוואה כל-מול-כל, אינדקס וחיפוש.
- `generated/corpus.bundle.js` — הקורפוס המעובד (27,310 יחידות: פסוקים + משניות) כקובץ script, כדי שיעבוד תחת `file://`.
- `generated/corpus/` — אותו קורפוס, קובץ לכל ספר (`node scripts/split-corpus.js`), עם `index.js` = רשימת הספרים. זה מה שהאתר טוען בפועל, דרך `corpus-loader.js` ולפי דרישה; `sw.js` שומר את הקבצים בדפדפן.
- `generated/corpus-manifest.json`, `generated/corpus-validation-report.json` — דוחות הקורפוס.
- `tests/run-tests.js` — בדיקות (דורש Node, למפתחים בלבד). `scripts/` — validate/build (זמינים בפרויקט המלא בלבד).

## הקורפוס
מקור האמת: `data/Tanakh` + `data/Mishnah` בלבד (102 קבצים). המקור לא שונה. `books.json` (מחוץ ל-data/) לא נעשה בו שימוש.
מבנה: `text[פרק][יחידה]` — יחידה = פסוק (תנ״ך) או משנה (משנה). לצורך גימטריה בלבד מוסר סימון שאינו חלק מהפסוק: תגיות HTML, הערות שוליים, סימני פרשיות `{פ}` `{ס}` `׆`, והקרי במקומות כתיב/קרי (נשאר **הכתיב**). מקף מפריד תיבות.
מקור הטקסטים ורישיונות השימוש בהם (חשוב לפני פרסום פומבי, למשל ב-GitHub): ראו [`ATTRIBUTION.md`](ATTRIBUTION.md).
קוד האפליקציה עצמו קנייני — כל הזכויות שמורות: ראו [`LICENSE`](LICENSE).

## נרמול
פונקציה אחת (`normalizeText`/`tokens`) משמשת חיפוש, גימטריה, אינדקס והשוואה: הסרת ניקוד וטעמים, פיסוק ורווחים; אותיות סופיות = רגילות. נשמרים `originalText` ו-`normalizedText`.

## שיטות
רגילה; עם הכולל (+1); עם מספר תיבות; עם מספר אותיות; מילוי (טבלת שמות האותיות `MILUI_NAMES`; ה״א=הא, וא״ו=ואו, ט׳=טית, פ׳=פא, צ׳=צדי — ניתן לשינוי); אתב״ש. אטב״ח: לפי הטבלה שהגדיר המשתמש (`ATBACH_DEFAULT` ב-engine.js, 22 אותיות: א↔ח, ב↔ז, ג↔ו, ד↔ה, ט↔צ, י↔פ, כ↔ע, ל↔ס, מ↔נ, ק↔ת, ר↔ש), ללא הגדרה ידנית.

## חיפוש והשוואה
החיפוש מחשב חלונות רצופים של תיבות **בתוך יחידה אחת בלבד** (two-pointer, כל השיטות תוספתיות) — לעולם לא חוצה פסוק/משנה/פרק/ספר. ההשוואה בודקת כל שיטה בצד א׳ מול כל שיטה בצד ב׳; כל התאמה מקבלת מספר, צבע ותווית.
